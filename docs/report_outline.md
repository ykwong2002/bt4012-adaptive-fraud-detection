figures in `outputs/figures/`. Paired seed-level 95 % intervals throughout (D17, `12_stats.py`).

## Professor's comments → where they are answered

1. *EDA, data preparation, alignment of raw text and timestamps with the graph.* §2 + §3.1, now on
   real data: the graph is rebuilt from the raw `metadata` with the published relation definitions
   (R-U-R same user; R-S-R product × star; R-T-R product × month) and the 800-review cap (D1); text is
   joined on (user, product, date, k-th occurrence) and the loader raises on any unmatched review
   (all 608,598 YelpZip reviews joined; `load_raw.py`); features are recomputed point-in-time so nothing
   after a review's date leaks into it (`features_pit.py`, tested); equal-count temporal windows (D3).
   Why YelpZip rather than YelpChi text: the YelpChi raw release never arrived (D18); YelpZip is the same
   authors' sibling release with the same labels and format (D19); the YelpChi `.mat` graph stays as the
   supporting track and its alignment story (no public index → review mapping) is stated in one sentence.
   EDA to show: class balance per window, the homophily table and histograms by relation and class (the
   camouflage evidence), degree CCDFs, the feature table with Cohen's d.
2. *Does confidence-based self-training reinforce normal-class bias; how to check and fix?* §3.5 + §4.3:
   yes, on both datasets: naive pseudo-labels shrink to 0.07 % (YelpZip) / 1.9 % (`.mat`) positives and
   balanced loss alone does not fix it (1.1 % / 6.0 %); per-class quotas and prior matching hold the share
   at the prior; the audit (share vs prior, community dispersion, probe minority recall, collapse rule) and
   the bootstrap promotion guard are the check and the fix; operating-point metrics catch a collapsed
   model that still ranks well.
3. *Justification of reconstruction and drift detection; practical implications, limitations,
   reproducibility.* §3.2 + §4.1 (fraud-centred edge AUC and the noisy-oracle bar justify when
   reconstruction is worth it, and explain the small real gain), §3.4 + §4.2 (calibrated, label-free
   monitor that works on real drift with 0 false alarms), §4.4 (what camouflage defeats), §4.5, §5.
